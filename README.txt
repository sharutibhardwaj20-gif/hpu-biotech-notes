HPU Biotech Notes — starter website
===================================

Files:
- index.html: homepage structure and text
- style.css: responsive design
- script.js: mobile menu and search

Preview locally:
1. Extract the ZIP.
2. Open index.html in a browser.

Publish free using GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new public repository named `hpu-biotech-notes`.
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings → Pages.
5. Under build/deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
6. Wait for the published URL shown on the Pages settings screen.

Important:
- This is an independent starter template, not an official HPU website.
- Semester cards are placeholders, not a verified current HPU syllabus.
- Add only original notes or materials you have permission to distribute.
- Paid PDFs, user accounts, secure downloads, and payment processing are not implemented in this static starter. These need a separate secure service/integration.
- Verify course structure and content against current HPU sources before publishing.
